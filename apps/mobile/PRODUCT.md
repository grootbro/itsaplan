# Product

<!-- impeccable:product-schema 1 -->

## Platform

ios

## Product Purpose

It's a Plan mobile is the Expo client for the existing issue-tracking workspace.
The user requested a substantial extension toward web feature coverage with a
minimal, native interface and code review. iOS is the configured release target;
Android code paths exist but Android release readiness is not established.

## Operating Context

Authenticated members work with projects, issues, assignment, states, priorities,
labels, dates, cycles, initiatives, checklists, comments, files, time logs and Inbox.
The existing API and its permissions define behavior. The app uses existing accounts.

## Capabilities and Constraints

Extend the daily workspace with project filtering, sorting, grouping, personal
project preferences, cross-project assigned tasks and quick issue actions.
Preserve existing issue flows. No new server business rules, dependencies, release,
production deployment or signing changes. The local ban on QA remains applicable.

## Brand Commitments

Preserve the It's a Plan name, restrained neutral identity and existing icon assets.
Use platform navigation, readable task lists and direct English interface copy.

## Open Decisions

Device validation, current deployed API compatibility, Android release identifiers,
dark appearance and server verification remain separate work.
